How it works

Balancing an equation

Every chemical formula is really a list of atoms. H2O means two hydrogens and one oxygen. The balancer reads each formula, counts atoms of every element, and writes them into a grid: one row per element, one column per species. Reactants count as positive numbers. Products count as negative numbers.

Then it looks for a set of coefficients that makes every row add up to zero. That is what "balanced" means: the same number of each atom on both sides. The math used is called Gaussian elimination, but you do not need to know it. The site just solves the grid and gives you whole numbers, because fractions like 1/2 O2 are usually written as whole numbers in textbooks.

Example. For C3H8 + O2 -> CO2 + H2O, the site finds 1 propane, 5 O2, 3 CO2, and 4 H2O. Check carbon: 3 on the left, 3 on the right. Check hydrogen: 8 on the left, 8 on the right. Check oxygen: 10 on the left, 10 on the right. Balanced.

Calculating molar mass

Each element has an atomic mass. Hydrogen is 1.008, carbon is 12.011, oxygen is 15.999. To get the molar mass of a formula, multiply each element's atomic mass by how many atoms of it appear, then add everything up. For H2O: (2 × 1.008) + (1 × 15.999) = 18.015 g/mol. That number is how many grams one mole of the substance weighs.

Why does the arrow matter?

The arrow separates reactants from products. The site accepts several forms: ->, =, →, ⟶, and a few others. If it cannot find one, it tells you what it saw and shows an example.

Predicting products

The "Find the products" tool works differently. It looks at the reactants you type and matches them against a database of known reaction types: combustion, single replacement, double replacement, synthesis, decomposition, and acid base neutralisation. If it finds a match, it proposes plausible products. This is a shortcut, not real chemistry. It cannot know every reaction, and it will get some exotic cases wrong. Use it as a starting point, then check the result by hand.
